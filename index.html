This site reads a published data snapshot built by GitHub Actions. Member records and official portraits come from Congress.gov; committee rosters are supplemented by the public unitedstates/congress-legislators dataset; chamber leadership is parsed from official House Clerk and Senate pages. Refreshing this page loads the latest published snapshot; the scheduled job checks sources every six hours. Source updates can lag, and failed validation prevents a bad snapshot from replacing the last good one.
